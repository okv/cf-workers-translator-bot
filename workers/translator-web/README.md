# Translator Web

This [CloudFlare Worker](https://developers.cloudflare.com/workers/) implements a simle WEB UI that can help you to learn some new words in different languages.

The worker itself tries to do as less as possible and uses the following libraries:

- [packages/translator](/packages/translator/) to translate words and phrases.

## Features

The WEB UI can:

- Translate words and sentences :tada:.
